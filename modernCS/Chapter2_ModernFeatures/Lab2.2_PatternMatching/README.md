# Lab 2.2: Pattern Matching

## Goal
Learn and practice C# pattern matching features introduced in C# 8.0 and enhanced in later versions.

## Key Concepts
- **Switch Expressions**: Modern switch syntax that returns values
- **Property Patterns**: Match on object properties
- **Type Patterns**: Match on types with conditions
- **When Clauses**: Add additional conditions to patterns
- **Positional Patterns**: Match on tuple elements

## Implementation
This lab demonstrates various pattern matching techniques:

1. **Basic Switch Expressions**: Using switch to categorize tasks based on properties
2. **Property Patterns**: Matching on specific property values and combinations
3. **Type Patterns**: Pattern matching on different types in a collection
4. **Positional Patterns**: Using tuples with pattern matching

## Key Features Demonstrated
- `{ IsCompleted: true }` - Property pattern matching
- `when` clauses for additional conditions
- Type patterns with `Task { ... }`
- Switch expressions returning strings
- Tuple deconstruction patterns

## Expected Output
The program will analyze a list of tasks and demonstrate different pattern matching scenarios, showing how modern C# can elegantly handle complex conditional logic.
